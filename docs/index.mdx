iso-topology is an open-source Go CLI and library for **2.5D isometric diagrams**.
Describe nodes and connections in D2, or compose a scene in YAML or JSON. The
renderer produces SVG you can use in documentation, design reviews, and READMEs.

## From source to diagram

<Steps>
  <Step title="Describe the architecture">
    Use D2 for automatic graph layout. Use YAML for explicit groups, replicas,
    annotations, geometry, and styling.
  </Step>
  <Step title="Render and inspect">
    Generate an SVG with the CLI. Open Studio to edit the source and adjust the
    diagram visually. Validate the result before sharing it.
  </Step>
  <Step title="Keep the source">
    Commit your diagram source with your project. Re-render it as the architecture
    changes, or call the same renderer from your Go application.
  </Step>
</Steps>
